Ich bin **Dominik**, ein leidenschaftlicher Software Engineer und Context Engineer mit Fokus auf skalierbare, KI-gestützte Lösungen und selbst gehostete Systeme. - 🧠 Fast alle meine Projekte basieren auf **Vibe Coding** und **Context Engineering** – für natürlich wirkende, kontextadaptive Systeme.
- ⚡ Ich experimentiere ständig: Infrastruktur automatisieren, DevOps mit KI verbinden und Technologien so bauen, dass sie autonomer werden.
